# 02. 데스크톱 앱 (Overlay) 명세

## 2.1 핵심 기능

### LoL 연동

- Overwolf SDK로 LoL 클라이언트 감지
- 게임 시작 시 자동 활성화, 종료 시 비활성화
- Overwolf 제공 LoL 이벤트로 현재 플레이 중인 챔프 자동 인식
- Riot API (Data Dragon)로 챔프·스킬·아이템 아이콘 로드

### 콤보 라이브러리

- 챔프 선택 → 등록된 콤보 목록 표시
- 로컬 저장 콤보 + 웹에서 다운로드한 콤보 통합 표시
- 콤보 검색·필터 (난이도, 태그 등)

### 키 바인딩

- 사용자 키 설정 변경 가능 (LoL 인게임 설정과 동기화는 안 함, 별도 관리)
- 콤보 재생 시 사용자 키 바인딩에 맞춰 표시 변환

### 녹화

- 단축키로 녹화 시작·정지
- 캡처: 게임 화면 (mp4) + 키 입력 시퀀스 (JSON, 타임스탬프 포함)
- 녹화 종료 시 자동 저장

### 편집

- 녹화된 영상·입력을 타임라인 형태로 표시
- 스텝 나누기 (구간 마커 추가)
- 각 스텝에 팁·주석 텍스트 추가
- 입력 추가·수정 (클릭, 평타, 평캔 등 별도 표기 가능)
- 영상 트리밍 (앞·뒤 잘라내기)

### 재생 오버레이

- 게임 위 투명 오버레이로 콤보 시연
- 입력 시퀀스 키캡으로 표시
- 타이밍 인디케이터
- 일시정지·반복·속도 조절

### 업로드·다운로드

- 편집 완료 후 웹에 업로드 (로그인 필요)
- 웹에서 받은 콤보 자동으로 라이브러리에 추가
- 커스텀 URL 스킴(`combo://`)으로 웹에서 바로 앱 실행

## 2.2 콤보 데이터 처리

### 녹화 시 캡처 항목

- 입력 시퀀스 (각 입력의 키·타임스탬프·종류)
- 입력 종류: 키보드 키 / 마우스 클릭 / 평타 / 평캔 / 아이템 사용
- 콤보 시작~종료 총 소요 시간
- 영상 (mp4)

### 연습 모드 표시 항목

- 입력 예시 (타이밍·순서)
- 사용자 입력 로그 (실시간)
- 콤보 시연 영상 (오버레이 또는 PiP)
- 결과 (입력 순서 일치 여부, end-to-end 시간)

> 성공/실패 판정은 Phase 1에선 보류. 입력 순서가 맞았는지 + 총 시간만 표시. 정확한 타이밍 판정은 Phase 2.

## 2.3 기술 스택

| 영역 | 추천 |
|---|---|
| 프레임워크 | Overwolf (Electron 기반) |
| 언어 | TypeScript / JavaScript |
| UI | React + Tailwind |
| 영상 처리 | ffmpeg.wasm 또는 네이티브 ffmpeg |
| 패키징 | Overwolf 스토어 + 자체 인스톨러 |
