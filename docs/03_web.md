# 03. 웹사이트 명세

## 3.1 라우트 구조

게임은 1급 시민으로 다룬다. 단순 필터가 아니라 게임별 페이지 트리를 가진다. 추후 게임 추가 시 라우트와 UI 컴포넌트를 함께 확장한다.

```
/                          홈 — 게임 선택 + 인기 콤보
/games/lol                 LoL 콤보 목록 (챔프·난이도 필터)
/games/lol/champions/:slug 챔프별 콤보 목록
/combos/:id                콤보 상세
/upload                    업로드 (게임 선택 후 게임별 폼 분기)
/users/:id                 사용자 프로필
/login                     로그인
/download                  데스크톱 앱 다운로드
```

추후 게임 추가 시 `/games/elden-ring`, `/games/arknights` 형태로 동일 패턴 확장.

## 3.2 페이지 구성

| # | 페이지 | 역할 |
|---|---|---|
| 1 | 홈 | 게임 선택 + 전체 인기 콤보 |
| 2 | 게임별 메인 | 해당 게임 콤보 목록·필터 |
| 3 | 캐릭터별 페이지 | 특정 챔프 콤보 목록 |
| 4 | 콤보 상세 | 콤보 정보·미리보기·다운로드·조건 |
| 5 | 업로드 | 게임 선택 → 게임별 폼 |
| 6 | 사용자 프로필 | 작성한 콤보 목록 |
| 7 | 로그인 | 인증 |
| 8 | 다운로드 | 데스크톱 앱 다운로드 안내 |

## 3.3 페이지별 상세

### 홈

- 헤더 (로고·검색바·로그인)
- 게임 선택 그리드 (LoL / 추후 추가)
- 전체 인기 콤보 (게임 무관)

### 게임별 메인 (예: /games/lol)

- 게임 헤더 (배너·게임명·콤보 수)
- 게임 특화 필터 — LoL은 챔프·난이도·태그·패치
- 정렬 (인기·최신·다운로드)
- 콤보 카드 그리드
- 페이지네이션

### 캐릭터별 페이지

- 캐릭터 헤더 (아이콘·이름·콤보 수)
- 난이도·태그 필터
- 콤보 카드 그리드

### 콤보 상세 (가장 중요)

- 헤더 (제목·작성자·게임·캐릭터·난이도)
- 액션 (다운로드·좋아요·공유)
- 영상 미리보기
- 입력 시퀀스 시각화 (게임별 아이콘으로 표시)
- **조건 섹션** (게임별 자동 렌더링)
  - LoL 예시: 레벨 6+, 스킬 가속 20+, 공격 속도 1.5+, 필요 아이템·소환사 주문
- 작성자 노트 (자유 텍스트로 상세 설명·상황·팁)
- 댓글
- 비슷한 콤보 추천

### 업로드 (3-step)

1. 파일 업로드 (.tutfile 드래그앤드롭) — 파일에서 게임 자동 인식
2. 정보 입력
   - 공통: 제목·캐릭터·난이도·태그·설명
   - 게임별 추가 필드 (LoL: 레벨, 필요 아이템, 소환사 주문 등)
3. 미리보기 후 게시

### 사용자 프로필

- 프로필 헤더 (아바타·닉네임·작성 콤보 수)
- 작성한 콤보 그리드

### 로그인

- 이메일 + Google + Discord OAuth

### 다운로드

- Windows 인스톨러 다운로드 버튼
- 설치 가이드
- Overwolf 설치 안내

## 3.4 핵심 컴포넌트

| 컴포넌트 | 사용처 | 비고 |
|---|---|---|
| 콤보 카드 | 홈, 게임별, 프로필 | 게임 무관 공통 |
| 입력 아이콘 | 콤보 상세, 카드 | 게임별 변형 — 키캡/스킬/아이템/소환사 주문 |
| 캐릭터 아이콘 | 전역 | LoL은 Riot Data Dragon |
| 영상 플레이어 | 콤보 상세 | 썸네일 hover 재생 |
| 작성자 카드 | 콤보 상세, 프로필 | 게임 무관 공통 |
| 게임별 조건 패널 | 콤보 상세 | 게임별 컴포넌트 분기 — `<LolConditions />` 등 |
| 게임별 업로드 폼 | 업로드 페이지 | 게임별 컴포넌트 분기 — `<LolUploadForm />` 등 |

게임별 변형 컴포넌트는 `components/games/lol/`, `components/games/elden-ring/` 같은 식으로 디렉터리 분리하면 추후 확장 시 명확하다.
