# 01. 프로젝트 개요

## 1.1 한 줄 정의

게이머가 게임 내 콤보·패턴·대응법을 기록·정리·공유·활용할 수 있는 **인터랙티브 오버레이 + 웹 플랫폼**.
"입력 + 화면 + 타이밍"이 결합된 재현 가능한 단위로 가이드를 제공하며, 게이머는 게임 위 오버레이로 따라하며 학습·연습한다.

## 1.2 프로젝트 목표

게임 내 컨트롤 및 애로사항 해결 — 콤보, 퍼즐, 보스 패턴 등 "하고는 싶은데 어떻게 하는지 모르는 것"을 재현 가능한 형태로 만들어 공유한다.

## 1.3 주요 기능

1. 게임 내 키 입력 녹화 및 오버레이 재생 (따라하기 학습)
2. 콤보·패턴 등록·공유 웹 플랫폼
3. 추후 확장
   - 보스전 패턴 및 대응법
   - 퍼즐 요소 대응법
   - AI 자동 챕터링·주석 생성

## 1.4 MVP 범위

- **타겟 게임**: 리그 오브 레전드 (LoL) — 챔피언별 콤보 연습
- **플랫폼**: Windows 데스크톱 오버레이 앱 + 웹사이트
- **핵심 흐름**: 콤보 녹화 → 편집 → 공유 → 다운로드 → 오버레이 연습

## 1.5 확정 사항

| 항목 | 내용 |
|---|---|
| MVP 게임 | LoL — 챔피언별 콤보 오버레이 |
| 확장 후보 | Elden Ring (가이드 수명 김), 명일방주 엔드필드 |
| 오버레이 방향 | 게임 무관 코어 모듈 + 게임별 모듈 분리 |

## 1.7 향후 계획

1. 녹화된 입력의 재생 오버레이 구현
2. AI 자동 챕터링·주석 생성 파이프라인 프로토타입

## 1.8 시스템 구성도

```
[데스크톱 앱 (Overlay)]  ←→  [백엔드 API]  ←→  [웹사이트]
        │                          │                  │
        ├─ Overwolf SDK            ├─ Auth            ├─ 로그인
        ├─ 키 입력 캡처 ✓          ├─ Combo CRUD      ├─ 콤보 탐색
        ├─ 오버레이 UI 초안 ✓      ├─ Storage (영상)  ├─ 다운로드
        ├─ 재생 오버레이 (WIP)     └─ Search          └─ 업로드
        └─ .tutfile 생성
```

## 1.9 열린 질문

| 주제 | 내용 |
|---|---|
| AI 활용 깊이 | 자동 챕터링·주석 생성을 어디까지 자동화할지 |
| 타겟 게임 우선순위 | LoL(시장 큼) vs Elden Ring(가이드 수명 김) vs 명일방주 |
| 오버레이 범용성 | 게임 무관 코어 모듈 + 게임별 모듈 분리 전략 |
| 수익 모델 시점 | 검증 후 마켓플레이스·B2B SDK 중 어디로 갈지 |
| 크래프톤 본부 가치 정렬 | 외부 게임에서 검증한 기술을 자체 게임에 이식하는 방법 |
| 경쟁사 리스크 | 유사 기능 경쟁사 존재 여부 및 모방 가능성 |
