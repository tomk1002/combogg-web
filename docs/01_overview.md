# 01. 프로젝트 개요

## 1.1 한 줄 정의

게임 내 캐릭터·무기별 콤보를 등록·연습·공유할 수 있는 **인터랙티브 오버레이 + 웹 플랫폼**.

## 1.2 주요 기능

1. 게임 내 캐릭터/무기별 콤보 등록 및 연습
2. 추후 확장
   - 보스전 패턴 및 대응법
   - 퍼즐 요소 대응법

## 1.3 MVP 범위

- **타겟 게임**: 리그 오브 레전드 (LoL) 단일
- **플랫폼**: Windows 데스크톱 오버레이 앱 + 웹사이트
- **핵심 흐름**: 콤보 녹화 → 편집 → 공유 → 다운로드 → 연습

## 1.4 시스템 구성도

```
[데스크톱 앱 (Overlay)]  ←→  [백엔드 API]  ←→  [웹사이트]
        │                          │                  │
        ├─ Overwolf SDK            ├─ Auth            ├─ 로그인
        ├─ Riot API (간접)          ├─ Combo CRUD      ├─ 콤보 탐색
        ├─ 입력 캡처                ├─ Storage (영상)  ├─ 다운로드
        ├─ 영상 녹화                └─ Search          └─ 업로드
        ├─ 편집기
        └─ 재생 오버레이
```

## 1.5 책임 분배

| 영역 | 담당 | 산출물 |
|---|---|---|
| 데스크톱 앱 (Overlay) | 팀원 A | Overwolf 앱 — 녹화·편집·재생 |
| 웹사이트 + 백엔드 API | 팀원 B | Next.js 웹 + API + DB |
| 공유 영역 | 양쪽 협의 | .tutfile 포맷, OpenAPI 명세 |
