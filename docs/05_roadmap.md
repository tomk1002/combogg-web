# 05. 작업 분배 및 로드맵

## 5.1 작업 분배

### 팀원 A — 데스크톱 앱

#### Phase 1
- Overwolf 프로젝트 셋업
- LoL 챔프 감지·아이콘 로드
- 키 입력·영상 녹화 (LoL 입력 카테고리 모두 처리: skill / attack / item / summoner_spell 등)
- .tutfile 포맷 구현 (game_specific 포함)
- 로컬 라이브러리 UI

#### Phase 2
- 콤보 편집기 (스텝 나누기·팁 추가·입력 카테고리 수정)
- 재생 오버레이 (게임별 아이콘 표시)
- 키 바인딩 설정

#### Phase 3
- 웹 연동 (다운로드·업로드)
- 연습 모드 (입력 로그·결과 표시)
- 게임 감지 로직 모듈화 (LoL 외 게임 추가 대비)

### 팀원 B — 웹사이트 + 백엔드

#### Phase 1
- Next.js 프로젝트 셋업 (게임별 라우트 구조 사전 설계)
- DB 스키마 + Prisma (game_specific JSONB 포함)
- 인증 (NextAuth + OAuth)
- API 기본 (콤보 CRUD, 업로드, 게임별 메타데이터)
- 다운로드 페이지

#### Phase 2
- 홈 (게임 선택 그리드)
- 게임별 페이지 (/games/lol)
- 콤보 상세 페이지 (조건 섹션·입력 시각화)
- 업로드 페이지 (게임별 폼 분기)
- 사용자 프로필

#### Phase 3
- 검색·필터 강화 (게임별 추가 필터)
- 좋아요·댓글
- 다운로드 카운트·통계
- 디자인 폴리시
- 게임 추가 시 컴포넌트 확장 패턴 검증

### 양쪽 협의 필요 영역

- **.tutfile 포맷 v1 확정** — game_specific 스키마 포함
- **API 스펙 (OpenAPI)** — Phase 1 초기에 합의
- **OAuth 토큰 흐름** — 데스크톱 앱이 어떻게 토큰을 받는지
- **커스텀 URL 스킴** — `combo://` 핸들링
- **Riot Data Dragon 캐싱 전략** — 양쪽 다 사용 (아이템·스킬·소환사 주문 아이콘)
- **input category 정의** — LoL의 입력 종류 합의 (skill, attack, attack_cancel, item, summoner_spell 등)

## 5.2 스프린트 일정

| Sprint | 기간 | 내용 |
|---|---|---|
| Sprint 0 | 1주 | 합의 — 본 문서 리뷰·확정 / .tutfile 포맷 / API 명세 v1 / Repo 구조 / input category 합의 |
| Sprint 1 | 2주 | 기반 — 앱: Overwolf+LoL 감지·녹화 / 웹: Next.js+DB+인증 |
| Sprint 2 | 3주 | 핵심 — 앱: 편집·로컬 저장 / 웹: 콤보 CRUD API + 업로드 페이지 + LoL 게임 페이지 |
| Sprint 3 | 2주 | 연동 — 앱↔웹 업로드·다운로드 / 커스텀 URL 스킴 / 콤보 상세 페이지 / E2E 테스트 |
| Sprint 4 | 2주 | 폴리시 — 앱: 재생 오버레이 / 웹: UI/UX·검색·조건 표시 / 베타 배포 |

**총 10주 / 약 2.5개월**
